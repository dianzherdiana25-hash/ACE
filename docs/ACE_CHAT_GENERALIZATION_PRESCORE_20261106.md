Does the exact integrated ACE Runtime v1, which stages only programs fitting train **and** validation perfectly, produce predictions on longer (out-of-development-length) strings that are more accurate than strong source-provided fixed-product selection? Does it detect an observationally indistinguishable semantic change? This assesses **existing fixed-representation generalization and admission safety**, not invention of a novel method. Distinct from open S3 PR #57 (XOR candidate vs a single-topology baseline on synthetic transfer). ## Fixed worlds, seeds, budgets

**Four nominal task families**, two independent seeds each `20261111,20261112` (8 nominal runs), plus two hidden-drift controls (10 total worlds). Task families, in exactly this order:

1. `ratio3`: count('a') == 3×count('b'), count-only, representable by existing counter (1,-3).
2. `ratio2_boundaries`: count('a') == 2×count('b') AND starts with a AND ends with b, representable by existing counter+fixed guard product.
3. `parity_a_odd`: count('a')%2==1, order-insensitive regular control, not in count-equality grammar; could be learned by finite-state DFA.
4. `boundary_same`: first and last symbols equal (and string nonempty), regular, order-sensitive; not in the existing fixed guard list.

Hidden `ratio3_late_flip` control uses **bit-for-bit identical** train+validation strings/labels and terminal word list to `ratio3` in the same seed, but **inverts all terminal labels**, under identical label and compute budgets. Model selection has no access to control identifier or terminal labels. Failure to detect the different world is unavoidable from identical observed data, so never claim open-world safe promotion.

**Splits and sampling** for all worlds:
- Train: all 63 binary strings length 0..5, source `r1.training_words()`. No sampling changes after scoring.
- Validation: 128 unique strings with lengths 6..15, stratified into exactly 64 positives and 64 negatives. Evaluator seed `710000 + seed + family_index`.
- Terminal: 128 unique length 24..36 strings, stratified 64 positive and 64 negative, seed `810000 + seed + family_index`. For hidden controls reuse matching nominal words then invert labels.
- Fixed, deterministic rejection/constructive generators, per-stratum maximum 100000 attempts and fail closed on insufficient samples. Ratio3 positive strings generated by shuffling a:b=3:1 counts at lengths divisible by 4; ratio2-boundary positives likewise ratio2 and enforced outer letters. For ratio2 negative examples sample *ratio2 count-matched but boundary-invalid strings*, making pure counter inadequate. Parity and same-boundary strings are generated randomly and stratified by true target labels. All worlds have class-balanced validation and terminal; disjoint train/validation/terminal lengths. Do not filter based on model outcomes.
- Total labels: 10×(63+128+128) = **3,190** public source-truth labeled observations across task instances; 1,280 terminal labels withheld from model selection. Terminal truth is observed only after the candidate/arms are selected and runtime stages/rejects.
- Each task uses a *fresh SQLite workspace* to avoid uncontrolled inheritance between trials; this measures **independent model acquisition** and not continual model retention. Workflow source checks and double replay enforce repeatability.

## Predeclared gates

- **G1 Engineering:** all ten worlds run using real source APIs, no terminal leakage, source SHA/protocol ancestry and two byte-identical full source replays; typed adversarial tests block changed labels, fake gate and promotion flags.
- **G2 Nominal evidence:** ACE runtime stages ≥4 of 8 nominal worlds AND its staged models obtain ≥90% terminal accuracy on all their staged tasks (count unstaged as missing coverage). Failure is a negative result, not a reason to reselect by terminal.
- **G3 Superiority:** learned `composition` has ≥32 more correct terminal predictions (≥3.125 percentage points over 1,024 nominal predictions) than the source-provided `fixed_product`. If not, superiority **REJECTED**. Compare per-family, not pooled only.
- **G4 Shift safety:** `ratio3_late_flip` must not lead to a **false safe-admission claim**. Because source runtime supplies no final-prediction abstention, open-world-safe status is **unconditionally false**. Measure fraction of shift controls that staged despite terminal mismatch; if any staged with <90% terminal, record observed false acceptance. `G4_safe_open_world` must remain FAIL.
- **G5 Reproducibility:** exact-sha source and committed pre-score text locked; deterministic outputs byte-identical twice; tests reject altered terminal score, invalid boolean/int aliases, spoofed source SHA, promotion status and altered baseline result.

**No scientific promotion** even if G1/G2/G3 pass. Additional hard limitations: public model-authored tasks and labels, non-matched compute, no independent evaluator custody, no domains beyond binary strings, no novel algorithm class. Report negative results and comparison on actual measured terminal.
