Commit this protocol before implementing/scoring its new experiment runner. The
binary v0.1/v0.2/v0.3 and runtime-v1 evidence remain unchanged. This is a new,
public synthetic, author-designed study, not independent sealed confirmation.
Science classification starts NOT_ASSESSED; OAIE and new mechanism-class

## Operational prerequisites and hypothesis

Repair nominal-storage acknowledgment, model-creator provenance, bounded input
and multi-family serialization before running the experiment. Use one persistent
runtime and reviewed family adapters for binary, integer arithmetic and weighted
key/door graph planning. Candidates remain closed data; native arbitrary-source
execution stays blocked if the real isolation canary fails. Log source hashes,
resource units, all failures, admission and retention separately from correctness.

H1: inherited typed ASTs can serve as charged subexpression macros in a later
arithmetic synthesis task, improving cold-search problem solving within the same
expanded grammar. H2: a data-conditioned decision-tree router over existing graph
planners can improve future-task execution against a strong source-selected fixed
planner. Both mechanisms are category 3 compositions of supplied operators or
methods. Importing S2/R6 is category 1; changing ceilings is category 2. Neither
hypothesis can establish category 4, new primitive/mechanism-class discovery.

## Fixed generations and arithmetic bank

Use three independent repetition seeds 6202601, 6202602, 6202603. The same fixed
method and protocol apply to all; never select a repetition from its score.

G0 controls: cold S2 training-guided beam and unguided enumeration. G1 learns
f(x,y)=x*y+2 and g(x,y)=x-y+1 from task labels only. G2 acquires f*f and f+g; only
exact train+validation-admitted ASTs join the parent library. G3 consists of four
future functions f*g, f-g, 2*f and g*g. Those G3 task labels are not used to
choose the G2 successor method. Every target may adapt to its own six training
and six validation observations; sixteen terminal observations are withheld from
all fitting, selection, parent ranking and admission. This measures transfer of
search structure to new target functions with labeled adaptation, not zero-shot
solution of unknown functions or transfer to a new representation class.

Coordinate generation uses deterministic Random(seed + 1009*task_index).
Six training pairs are sampled without replacement from [-3,3]^2; six validation
pairs from [-5,5]^2 excluding training; sixteen terminal pairs from [-12,12]^2
excluding both development splits. All pairs within a task are unique. These
ranges are bounded by S2 input contracts. Store input/label hashes and raw scores.

Macro candidates use at most eight previous admitted parents, ranked on target
TRAIN labels with expanded-node costs charged; retain at most four parent seeds.
Seed pool is those parents plus six original terminals (x,y,0,1,2,3). Enumerate
canonical one-step add/sub/mul compositions, including self-composition, plus
seed programs. Expanded depth<=4, expanded operations<=7, scored candidates<=800,
training-work ceiling100000 for both macro, beam and enumeration. Freeze an
at-most-eight training-ranked shortlist before validation. No hidden zero-cost
parent calls: interpret expanded AST nodes. Log all source-acquisition labels,
parent acquisition work, proposal work, selection work and audit replay work.
Equal ceilings alone are not evidence of equal actual compute; compare observed
work and report unmatched quantities rather than assert a fair efficiency win.

Arithmetic gate A: G3 admitted exact-terminal task count exceeds BOTH cold beam
and enumeration by at least 2 of the 12 paired future trials. Also report every
seed/function result, all-candidate diagnostic accuracy, admission coverage and
complete acquisition/selection costs. A tied/losing result rejects the advantage
hypothesis; no success threshold or bank may be changed after scoring.

## Planning bank and generations

Use the same three repetition seeds, offset by 200000. Build new connected
weighted grid graphs, with four-neighbor edges and independent integer weights
1..7. Keys are sampled without replacement from internal nodes; locks are an
explicit empty list for nominal tasks. Start is node0, goal is the final node;
all keys must be collected. The evaluator computes exact full-state Dijkstra
cost with an implementation separate from the R6 planner. Generate no candidate
using task names, oracle calls or terminal labels.

G1 uses six train and six validation graphs: repeat widths3 and4, square height,
key counts0,1,2. Distinct seeds make every graph input unique. G2 uses six train
and six validation graphs with square widths4 and5 and key counts0,1,2. G3 has
six future graphs with square width6 and rectangular width8,height6, key counts
0,1,3. Each generation/repetition uses distinct seeds at offsets10000*g+100*i;
train and validation use different additional offsets0 and5000; terminal uses
9000. Publish exact source generator and hashes before interpreting outcomes.

Three static controls are unchanged R6 hier_replan, astar_metric and dijkstra.
Every actual rollout has the same expansion cap1800 and source instrumented-work
cap2200. Router features are ONLY observable key_count and node_count; never
inspect shock or expected cost. Thresholds derive only from distinct training
features excluding maximum, at most eight deterministic order statistics per
feature. Enumerate unequal method leaf pairs, training-rank by exact cost then
execution work then canonical ID, freeze<=8 router candidates before validation.

A fit caches the three actual static outcomes per train/validation instance and
charges those rollouts to source acquisition. Counterfactual router scoring and
ranking are also counted. Compare all three static planners and the source-best
fixed choice on the same data. G1 and G2 each produce immutable selected policies;
G3 terminal graphs never choose a router or its thresholds. Report future costs,
optimal correctness, success coverage, actual instrumented work, failed actions,
replanning and routing-decision work. Graph labels are nonnegative optimal costs;
a failed None prediction is an abstention, never a correct unsolvability label.

Planning gate P: G2 successor must not lose optimal-correct future tasks against
source-best fixed, and must reduce summed actual future source work by>=10%,
including its routing decisions separately. Also compare against every static
control, count source-selection overhead and state which controls dominate.
This is a bounded execution-work hypothesis, not physical FLOP or latency proof.

## Retention, controls and acceptance

Retain old program bytes and evaluate original source capabilities after later
generations. Distinguish exact artifact retention from shared-model lifelong
learning. Report both G1 and G2 on the SAME future bank; no terminal-driven
replacement of a successor is permitted. Report family-macro outcomes separately
from pooled example accuracy; adding an authored adapter is not autonomous
cross-family discovery. Actual cross-family method transfer remains unproven.

Arithmetic negative controls: separately permute source labels before proposal;
fit is never given the true function. Also complement terminal truth for the
G1 f task while keeping its development history identical: the frozen program
must remain unchanged and any false acceptance is preserved. Graph controls add
a hidden closure to an existing low-ID edge on each future graph; report actual
recovery and hindsight cost separately, never call that safe unknown-world
adaptation. Include source labels increased by1000 as an impossible-fit control.

All positive, negative and incomplete trials must be archived. Require two
complete decision/evidence replays after stripping ONLY measured wall/CPU timing;
programs, hashes, work counters and metrics must match. Link exact commit and CI.
Public score gates are provisional diagnostics. Scientific acceptance remains
HOLD without stronger independent task/evaluator custody and failure accounting.
A successful integration, demo, unit suite, or one passing gate is not completion.
