# S2 prescore — neutral equivalence archive (2026-11-09)

Base main SHA: b81c076ef0f326331f81cb9c0678d6baa3b3250f. Exploratory public synthetic development study, NOT independent sealed confirmation.

Hypothesis H1: a bounded neutral structural mutation archive that retains two observationally equivalent integer linear programs before one new labeled counterexample improves exact post-adaptation prediction success by >= 10 percentage points over the strongest of (i) fixed DSL enumeration, (ii) no-mutation greedy, (iii) random proposal, (iv) equal-cost exhaustive search, on 24 deterministic task/seed pairs. Reject if improvement < 10 pp, including ties. No claim of new primitive: integer constants, x, y, multiplication and addition are researcher-authored.

World: f(x,y)=a*x+b*y, a,b in {-2,-1,0,1,2}, excluding (0,0). 24 coefficient pairs, sorted lexicographically, seed = task index 0..23. Public development partition first 8 pairs; disjoint evaluation partition remaining 16 pairs. Training inputs (1,1),(2,2); one adaptive counterexample input (1,-1); terminal inputs (-3,2),(4,-1),(-2,-4),(3,5). The terminal labels are not supplied to search, only to final measurement. A candidate succeeds if it matches all four terminal labels. Report train-fit coverage, expressivity (target in DSL), overfitting (training-perfect but terminal-wrong), and outside-grammar negative control f(x,y)=x*y (no linear DSL program can fit all terminal points). This is a public diagnostic, not a sealed holdout.

All five arms use max 25 scored proposals per task and exactly 3 environment labels (2 training, 1 counterexample). Proposal costs counted as candidate evaluations and interpreted arithmetic operations; CPU process_time recorded. Archive starts from a training-consistent coefficient pair and proposes neutral mutations (a+1,b-1) and (a-1,b+1) within bounds, retains up to two distinct programs; after counterexample selects best matching program. Fixed enumeration evaluates 25 lexicographically; no-mutation repeats initial candidate; random proposes seeded shuffled coefficient pairs; exhaustive evaluates all 25. For fairness, all may use the counterexample to select among their evaluated candidates; archive can only select from its two retained candidates. If archive's initial pair cannot reach target via one mutation, count failure; do not change algorithm after seeing results. Negative result retained.

Budget cap: 24 tasks x 5 arms x 25 proposals = 3000 proposal evaluations; 24 x 3 = 72 unique environment labels, reused across arms; 24 x 4 = 96 terminal labels for measurement; negative control additional 4 terminal labels. No paid oracle. If protocol ambiguity or implementation defect arises, record deviation and mark exploratory, not success. Preserve E1.4/E1.4aa and all HOLD/NOT_ASSESSED.
