# S1-Z preregistration — counterexample diversity in falsification (2026-11-07)
Status: exploratory public synthetic; no sealed heldout and no ACE/OAIE claim.
Prior S1-X chose among fixed hypotheses; F10 PR #73 owns structural generation. This study ONLY selects falsification probes for a common fixed candidate set; it does not generate hypotheses.

Hypothesis H: diversity-aware sequential counterexample selection reduces false acceptance of invalid candidate hypotheses by >=20% relative to EACH random, static and novelty-only control, at equal 8 binary evaluator labels per candidate, without reducing correct acceptance of valid candidates by >5 percentage points versus static.
Model: each world contains one proposed 12-bit Boolean predictor h and one ground-truth predictor g. Inputs are 6-bit vectors (64 total). Valid world h=g. Invalid worlds differ at 8 inputs (clustered or scattered). A binary label returns g(x) for the chosen input; compare with h(x). Every arm may choose from same 64 inputs and knows h but not g. Acceptance iff no mismatch observed after 8 labels. There is no ability to observe error location before querying.
Proposal strategies: random samples without replacement; static lexicographic first 8; novelty-only chooses inputs with maximum Hamming distance from prior queried inputs; diversity-aware chooses input maximizing minimum Hamming distance to prior inputs, with deterministic lexicographic tie-break. Static ranking and diversity are deterministic. Equal evaluator labels per candidate, 8 for every arm even after detection.
Precommitted counterexample: if invalid hypotheses' errors are concentrated in a lexicographic prefix, static can beat diversity; if errors lie in unseen suffix, all strategies can fail. Negative controls: valid hypotheses (false rejection), shuffled random labels (likelihood failure), and observationally equivalent candidate pair (no distinguishable input).
Generation: independent public synthetic development seeds 1100..1131 and evaluation seeds 2100..2355, each seed generates one valid, one clustered invalid, one scattered invalid, one random-label world. Ground truth g(x) is parity of bitwise AND of x and a nonzero 6-bit mask, XOR intercept. h=g for valid; invalid flips exactly 8 locations. Clustered invalid flips 8 consecutive input indices with start drawn uniformly from 0..56; scattered invalid flips 8 uniformly selected unique indices. Random-label oracle returns independent Bernoulli(0.5) values for every query, with h=g as baseline. Each world uses a fixed seed, and arms receive identical world/oracle outcomes (random-label outcomes fixed by input, not call order). For each method, 256 seeds x 4 scenarios x 8 labels = 8192 labels; 32768 total evaluation labels. Development data is diagnostic only, not for threshold tuning.
Metrics: false acceptance rate per invalid scenario, true acceptance on valid, model-independent empirical mismatch detections / labels; CPU process time and query selection operations, trials and labels. Report stratified results and negative cases. Primary comparison: pooled clustered+scattered invalid false acceptance vs EACH baseline. Secondary gate: valid acceptance within 5 percentage points of static. Reject if either gate fails. No hypothesis of calibrated posterior information gain: binary mismatch rate is a proxy for informative falsification labels, not Shannon information gain. CPU not matched; explicitly flag.
No repeated tuning after evaluation. Report actual executed code SHA256, protocol commit, evidence and all negative outcomes.
