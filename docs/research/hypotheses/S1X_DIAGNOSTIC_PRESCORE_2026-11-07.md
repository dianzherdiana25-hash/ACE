# S1-X prescore — diagnostic hypothesis identification (2026-11-07)
Scientific status: public synthetic exploratory; NOT_ASSESSED. This is *selection among generated compositional hypotheses*, not proof of autonomous discovery.
Question: can posterior-adaptive diagnostic selection identify a hidden 4-bit Boolean composition more efficiently than matched controls when queries have identical semantics?
Hypothesis: posterior expected entropy reduction (EIG) selection will improve held-out exact hypothesis identification by >=0.05 absolute over BOTH random and static ranking and improve realized reduction in Shannon entropy of the true-hypothesis distribution by >=20% per label over BOTH. Reject if either criterion fails on clean evaluation; negative controls must be reported, not optimized away.
Universe: 16 hidden four-bit compositions h=0..15, each interpreted as a conjunction of four latent binary switches. Diagnostic queries q=1..15 return parity(popcount(h & q)), flipped independently with probability 0.1. Query semantics, likelihood, candidate set and four-label budget identical for all arms. Development prior p(h) proportional to exp(-0.45 popcount(h)); evaluation clean prior is same generative law but independent seed. Adversarial shift uses complement-prior p(h) proportional to exp(-0.45 popcount(15 xor h)); misspecified likelihood uses flip probability 0.35; null oracle produces fair random labels independent of h.
Predeclared seeds: development 111, evaluation 211, shifted 311, misspecified 411, null 511. 256 worlds per scenario; all 4 arms evaluate identical h and deterministic oracle noise per (world,query), to preserve paired comparison. Arms: EIG adaptive; static precomputed EIG order using initial prior without conditioning; random unique masks; equal-budget uncertainty sampling choosing query whose predicted positive probability is closest to 0.5. Four unique diagnostic labels per world; deterministic tie-break lowest mask, random seed 991+scenario. Posterior Bayes update uses model flip 0.1, never learns from evaluation. Prediction argmax posterior. Report exact correct counts, empirical cross-entropy improvement relative to initial prior in bits/label (true h log probability before/after), model posterior entropy gain separately, CPU process time, trials, labels and candidate-query scoring operations. False certainty: fraction posterior max >=0.9 but wrong; null has no meaningful correct h and is scored only for false confidence.
One implementation and one bounded run only; no parameter search. No touching sealed holdouts. Record main SHA and protocol/code commit SHAs; retain all negative results. Do not promote science based on unit tests.
