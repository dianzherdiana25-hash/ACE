# S1-AA preregistration — observation-only adaptive falsification (2026-11-07)
Status: PRE-SCORE. Owner S1. This is a new test of label-feedback query selection, not F10 structural proposal generation.
Hypothesis H-AA: A Beta-Bernoulli per-feature adaptive policy reduces false acceptance at least 20% relative to BOTH random and diversity-only, on EACH of nominal and feature-reversed disjoint evaluation families, with eight queries per trial. A static feature-priority arm is a third control.
Worlds: public synthetic 4-bit query vectors (16 choices). Each world has hidden error predicate depending on two bits, either conjunction (nominal) or XOR (shift), with one of four bit-pair locations and one of four polarity settings; the candidate is false on predicate-positive queries. The policy never receives the predicate or location. Seeds 0..127 development and 10000..10127 evaluation; use evaluation only once, no tuning. Nominal and shift worlds are disjoint by predicate family. Negative controls: independent random labels and all-zero indistinguishable oracle. 8 labels per policy per world; same oracle and initial candidate/query pool, distinct policy RNG. Each query label is one evaluator call, including repeats; policies cannot query same vector twice.
Adaptive: maintain Beta(1,1) risk estimates per (bit index, bit value) from observed error labels, choose unqueried vector maximizing mean of four posterior means, tie-break seeded RNG; first query seeded random. Diversity: farthest Hamming distance from prior queries. Static: fixed lexicographic order. Random: random without replacement. Stop decision after eight labels: reject candidate if any error observed, else false accept on worlds with >=1 hidden error. Information: record true error prevalence and log-loss reduction relative to initial prior as descriptive proxy, not claim Shannon mutual information. CPU process and label/trial counts recorded.
Acceptance: adaptive false-acceptance relative reduction >=20% vs BOTH random and diversity on EACH nominal and shift evaluation, with no increase in false rejection on all-zero oracle. Reject otherwise. Report every negative result; no promotion beyond EXPLORATORY / NOT_ASSESSED. No external oracle or frozen data.
