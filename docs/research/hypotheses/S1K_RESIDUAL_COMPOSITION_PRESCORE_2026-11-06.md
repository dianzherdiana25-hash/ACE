# S1-K preregistration — residual-guided compositional proposals (PUBLIC SYNTHETIC)
Frozen before implementation/execution. Research question: can a generator that composes previously unseen Boolean expressions from observed residuals improve unseen-input prediction versus random and static proposal order, under identical evaluator labels and candidate-scoring budgets? This tests bounded instance generation, NOT new operator-class invention.

Task: six-bit Boolean inputs (64 rows). Training inputs 32 selected uniformly without replacement; disjoint 32 terminal rows. Each world target is XOR of two distinct literals, AND of two literals, or an adversarial 3-way parity target (not in the two-literal grammar). Candidate grammar: constants, literals, and pairwise XOR/AND expressions. All arms use the SAME 32 training labels and <=32 candidate scores, with no terminal access until selection. Guided arm proposes pairwise expressions in decreasing residual-alignment score computed from training labels; random arm shuffles candidates; static arm fixed lexical ordering. Because guided ranking can itself evaluate all candidate predictions, account for ALL candidate-example computations, and match the same 32-candidate scoring allowance in every arm. Candidate selection minimizes train error among examined candidates, ties resolved lexicographically. The guided ranking uses training labels to rank all candidates and therefore has an extra computation advantage: explicitly measure and report this confound; no claim of compute matching if not corrected.

Development seeds 0..63; terminal seeds 10000..10255. Acceptance requires guided terminal accuracy >= random AND static by >=0.10 absolute on BOTH XOR and AND target families; no >0.05 increase in false confidence on parity adversarial family. Report family-wise means, paired differences, exact labels/trials/CPU, distinct semantics and prediction entropy change per label (proxy only). Reject otherwise. No sealed holdout; no OAIE claims. Preserve negative outcomes.
