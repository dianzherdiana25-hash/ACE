## Narrow correction after audit

On this session's isolated branch, `SelfEvolutionEngine` now requires the router's successful local inference contract, nonempty actual output, model identity, recorded inference event and discovered readiness before setting `backend_healthy`. Failure produces `HOLD` and zero throughput. Word-count throughput is explicitly labeled an estimate, and inference health is not task verification. Factory availability no longer produces a verified capability promotion. The one known legacy factory marker emitted unconditionally by this method is moved to `RETEST_REQUIRED`; unrelated existing evidence is retained without claiming a new verification. Historical receipts/evaluators are unchanged. Targeted test results are recorded in the session checkpoint.
