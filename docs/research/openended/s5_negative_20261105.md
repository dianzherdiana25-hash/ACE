## Precommitted falsifiable hypothesis
Under matched 40 proposals per arm, QD archive's mean best disjoint evaluation score exceeds BOTH greedy and random by >=2.0 points. Reject if either difference <2.0. Five arms: QD archive, greedy, random drift, fixed curriculum, and QD without archive. Eight development seeds (0..7) and eight evaluation seeds with separate RNG streams (+100000); 40 proposals per arm. This is a public synthetic methodological stress test, **not blinded scientific confirmation**.

## Task and accounting
Each candidate is a 16-bit integer. Four random 16-bit target strings define synthetic tasks. At each 10-step phase, public reward scores agreement on one 4-bit mask; evaluation uses the other 12 bits and is not fed into candidate selection. QD archive uses 4-bit behavioral descriptors (candidate low nibble), retaining the highest public-score candidate per descriptor. The no-archive arm samples fresh candidates without persistent elites. Fixed curriculum enumerates researcher-specified masks. 5 methods × 8 seeds × 2 splits × 40 trials = **3,200 proposals**, four public labels each = **12,800 public synthetic target-comparison labels**; evaluation calculations are separate and not purchased labels. Original local run process CPU: **0.00848 s** (host-specific, not a portable performance guarantee).

## Limitations and falsification follow-up
The evaluation score changes mask with time and is not a true separate task-family distribution; only random seeds are disjoint. Training and evaluation share the same latent target strings within each arm, so this is **not independent OOD confirmation**. The curriculum and 4-bit descriptor are researcher-authored; a larger set of predetermined masks is not open-ended growth. Greedy's global incumbent comparison across shifting reward masks is a confound; this is a first negative diagnostic, not a decisive algorithm ranking. No claim of OAIE, unbounded discovery, or scientific GO.
