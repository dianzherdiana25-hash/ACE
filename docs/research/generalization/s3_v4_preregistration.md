# S3 v4 preregistration — public synthetic non-oracle parity transfer
Status: PUBLIC DEVELOPMENT / NOT CONFIRMATORY. Frozen E1.4 and E1.4aa not used. This protocol is committed BEFORE implementation or scoring. Parent main SHA a69f713d894db760d8a63bc332ba68bd8b0c2d1d. New question distinct from S3 v1-v3: can a **learned**, rather than supplied, invariant beat a matched single-topology selector?
## H1 and prespecified decision
Across exactly 24 paired seeds 6000..6023, a two-source learner (32 chain + 32 star labels) will reduce false acceptance by **at least 4/24** compared with a 64-chain-label learner, with <=12/24 abstentions, mean regret not higher, and equal 64-label selection budget. ACCEPT only if ALL hold; otherwise REJECT. Report results even if zero differences. No threshold tuning after seeing evaluation.
## World generator and separation
Five independent fair bits per row; true label XOR of all five bits, withheld from learner. Observed features: five bits, marker, and edge parity (edge sets: chain [(0,1),(1,2),(2,3),(3,4)], star [(0,1),(0,2),(0,3),(0,4)], branch [(0,1),(0,2),(1,3),(2,4)]). Marker agrees with label with probability 0.95 in source and 0.10 in branch evaluation. Independent deterministic Python random.Random streams seeded via 100000*trial+split_code, where split_code=11 chain, 17 star, 29 branch, 41 adversarial, 53 label-inversion. Both arms get identical 32 chain labels; one-source control receives 32 additional independent chain labels (split_code 13), two-source receives 32 star labels. Branch evaluation: 128 examples, labels used for reporting ONLY. Negative-control evaluation: 128 branch examples with independently randomized labels, distinct stream 41. No E1.4 data or confirmatory heldout.
## Learner and fixed controls
Search exactly 64 candidate XOR functions (all 32 masks over five bits times intercept 0/1), plus marker, edge parity, and constant zero = 67 candidates. Candidate functions are generated from a fixed grammar, **not given true target mask**. Rank by training errors, then complexity (number of bits used plus intercept; marker/edge/constant cost 1), then deterministic candidate index. Abstain if best training errors > 3/64 OR if first- and second-best candidates have equal errors (after ranking, compare raw error counts). No adaptation to evaluation labels. Both arms use identical candidate count, label count, and prediction budget.
## Metrics and controls
False acceptance per seed = selected non-abstaining candidate has >12 errors on 128 branch examples; abstention rate; regret = branch errors minus best achievable candidate branch errors (only defined for non-abstaining, and report unconditional penalized regret using 128 for abstention); CPU process_time seconds, number of candidate-row evaluations, labels selection and reporting, trials. Negative controls: random-label branch must not be claimed as generalization; invert all source labels in a separate diagnostic run (selection-only; no eval labels fed back); order/tie sensitivity is checked by deterministic candidate order reversal diagnostic. Reachable counterexample: first branch row where marker disagrees with true label, or report none. Leakage sentinel: recompute selected candidate after permuting evaluation labels while holding training fixed; any change is a FAILURE of custody.
## Interpretation
This is a bounded falsification on public synthetic development data. The XOR grammar contains the true function but does not reveal which mask is correct; results do NOT establish autonomous primitive discovery, open-ended generalization, or OAIE. No CI, merge, deployment, paid labels, or protected-path edits.
