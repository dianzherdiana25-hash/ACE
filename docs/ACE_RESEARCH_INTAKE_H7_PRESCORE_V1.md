## Target bank generated without response-based filtering
24 worlds = 4 R1 supplied base mechanisms `equal_counts`, `a_mod3`, `contains_ab`, `dyck` × 3 target feature lengths (5, 6, 7) × 2 task IDs per combination, lexicographic family/length/id ordering. Deterministically draw targets from `random.Random(2026110601 + 100000*base_index + 1000*target_length + task_id)`; draw exactly length independent random a/b symbols. **Only syntactic filter:** reject a generated target unless it contains >=2 a and >=2 b and does not equal the other target in the same base/length group. Never reject based on train, validation, or terminal labels. Cap 10000 draws/group, otherwise HALT. The exact selected targets are recorded in terminal evidence for reproduction but never passed to `discover`.

Truth on every query/terminal word `w` is `truth_base(base,w) XOR (len(w)>=6 and target in w)`. Since base is supplied and correct, model the residual bit `true_label XOR truth_base(base,w)`, and primary metric is *residual* balanced terminal accuracy, equivalent to final-label accuracy. Source base knowledge is privileged and not evidence of autonomous base learning.

For each task (zero-based global index), sample **128 unique training query strings** from all binary strings lengths 6..12 using `Random(43000000 + index)`; sample **128 disjoint validation query strings** from the complement with `Random(44000000 + index)`. Uniform over the distinct query-pool strings, no positive-label conditioning. 128 train+128 validation oracle labels/task; neither target name nor truth enters candidate construction except through these residual labels. Source H7 caps proposals and operations. Validation is used only for acceptance, never to refit.

Two separately reported terminal distributions, both disjoint from queries by length:
1. **Natural**: 256 unique uniformly sampled strings from all binary words of lengths 13..16, with `Random(45000000 + index)`. This distribution may have low trigger prevalence and is not evidence of robust positive sensitivity.
2. **Balanced feature**: deterministic 128 target-containing strings and 128 strings with *no* target occurrence, sampled without replacement from lengths 13..20. Use `Random(46000000 + index)` and a bounded max 200000 draws from uniform length 13..20 and uniform independent symbols. Candidate rejection based *only* on target occurrence is permissible for the **terminal metric sampling** and forbidden for train/validation/model choice. Exhaustion -> HALT. The balanced set is evaluation-only, never passed to any learner, and its score is the preregistered primary metric.

## Arms and costs
- **H7 unchanged** `discover(train_residual, validation_residual)`: if it rejects/abstains from making a *new feature*, the prediction **falls back to supplied base**. Record acceptance separately from actual semantic abstention. H7's interface does not abstain from predicting final output.
- **Base-only**: residual always false, 50% balanced terminal accuracy, no fitted feature.
- **Fixed H6 five literals** via source `frozen_selection`, same 128+128 labels, different search compute.
- **Expanded bounded grammar diagnostic**, not a promoted ACE learner: enumerate all contiguous 2..7-grams found in *positive training residual words* (at most 254), sort short-then-lex, accept first with zero training+validation errors and >=2 positive residuals in each; read-only term matching, no generated Python code. Uses the same oracle label counts but more proposal comparisons; not compute matched, so it is a diagnostic *representation ceiling* rather than fair algorithmic superiority.
- Record candidate counts and comparisons for expanded class, target presence in training positives, selection, false acceptances and first errors. Do not use retrospective holdout oracle for model selection.

## Predeclared gates; scientific decision
- **G1 (in-class length5):** H7 accepts >=6/8 newly constructed features, balanced primary mean accuracy >=0.90 and advantage over fixed base >=0.15.
- **G2 (outclass length6/7):** at least 14/16 H7 tasks decline feature acceptance AND **zero accepted tasks** have balanced terminal accuracy below 0.90. This is safety *within these public worlds*, not a universal OOD certificate. Fallback final predictions must still be scored (an abstention from feature selection is not final-label abstention).
- **G3 (expanded comparator):** diagnostic 2..7-class accepts >=12/16 outclass tasks with >=0.90 balanced terminal accuracy; if it fails, do not blame H7 solely for a grammar ceiling when data may be insufficient.
- **G4 (open-world):** even if G1–G3 pass, a target that flips only after input length 20 is indistinguishable on all queries. Any system returning forced binary predictions without externally validated semantic abstention remains `OPEN_WORLD_HOLD`. No automatic deployment or broad capability claim.
