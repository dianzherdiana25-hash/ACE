# Aksi berikutnya untuk Work atau Codex

1. Mulai dari kepala `research/e1.3-design`. Baca [status](CURRENT_STATE.md), [desain E1.3](design/e1.3/E13_DESIGN_v0.1.md), dan [pekerjaan GitHub #1](https://github.com/dianzherdiana25-hash/ACE/issues/1). Jalankan regresi, [replay pembanding](code/e13/README.md#pilot-pembanding-terpisah), dan [replay sintesis](code/e13/README.md#pilot-sintesis-dan-pewarisan-v01) dari checkpoint yang ditautkan.
2. Siapkan selection melalui jalur evaluator terpisah. Gunakan blok motif baru yang melampaui perubahan konstanta atau readout. Simpan generator, oracle dan label di luar checkout kandidat. Audit struktur aturan, perilaku pada saksi, hash tugas, tumpang tindih input, dan ketidakjelasan demonstrasi terhadap kedua bank development. Publikasikan digest dan status, sedangkan data tetap di jalur evaluator.
3. Samakan kesempatan dan kebijakan anggaran antar kondisi, ukur CPU fit, prediksi dan evaluator, dan ukur biaya pencarian saat berhenti lebih awal. Profilkan selection dan pilih B* hanya setelah prasyarat valid. Pertahankan status `UNKNOWN` untuk ekuivalensi yang belum lengkap.
4. Siapkan daya, penguncian protokol dan audit reproduksi teknis. Jalankan konfirmasi hanya setelah seluruh gerbang lulus.

Gunakan CPU lokal, anggaran Rp0, dan kontrak checkpoint pada [piagam](PROJECT_CHARTER.md).
