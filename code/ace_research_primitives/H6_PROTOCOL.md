# ACE R1 H6 — preregistered, bounded distinguishing-query experiment

**State:** PUBLIC SYNTHETIC DEVELOPMENT; preregister before implementation or outcome inspection; SCIENTIFIC NOT_ASSESSED. Commit only within `code/ace_research_primitives/` on `research/chat-r1-primitives`. No edits to main, frozen E1.4, or other agents.

## R1-specific question, not R7/S2
This experiment asks whether a representation-hypothesis pair consistent with initial traces can be **empirically distinguished** with bounded additional oracle labels. Unlike R7, this does not optimize general uncertainty calibration or broad active learning. Unlike S2, it neither mutates source programs nor searches arithmetic expression grammar. Unlike autonomous primitive discovery, **both candidate mechanism classes are supplied by the researcher**; success is only a query-design mechanics demonstration. An adversarial open-world test explicitly checks false certainty under missing mechanisms.

## Fixed bank and nonleaky splits
- Alphabet {a,b}; training includes all 63 strings of length 0..5. Both candidate models agree on all training words.
- Eight source predicates in fixed order: equal counts, count(a)%3==0, contains ab, Dyck-1, ends ba, no bb, odd length, and nonempty same-first-last. Five 5-character triggers in fixed order: `aaaaa`, `aaabb`, `ababa`, `bbbaa`, `bbbbb`.
- **80 in-class source worlds**: 8 predicates × 5 triggers × 2 true hypotheses (base or switched). Hypothesis H0 is the base predicate; H1 flips the base label if and only if word length >=6 **and** the word contains its assigned 5-character trigger. Truth for the two worlds at each base/trigger pairing is H0 and H1 respectively. No target ID is passed to learner or selector.
- Candidate-query pool is **all 1,984 binary strings of lengths 6..10**, in length-then-lexicographic order. Every selected query must be in that pool; its oracle label is acquired once. Both candidates fit the entire initial 63-word bank. For active strategy, scan model predictions for a disagreement and query first such string. Baselines: (i) one string uniformly sampled from the same pool using `random.Random(20261106 + task_index)`; (ii) a stronger **random-disagreement** baseline that samples uniformly among every candidate-disagreement string with the same seed. Each method receives one independent oracle label; do not share labels across arms to claim resource savings.
- A hypothesis is **accepted** only when the single observed oracle label differs between candidate predictions and matches exactly one; when both candidates predict the same label, **abstain**. Never guess on ties. Classification score = correct hypothesis identification / 80 (abstentions count as no identification). Also track queries, disagreement, selected index, query hash, abstentions. This is binary deterministic label feedback, not stochastic.
- Unseen terminal holdout: for each world, 256 unique words of length 11..13 sampled with RNG `random.Random(20261106 + 100000 + task_index)` from the enumerated pool, without replacement. Holdout must not enter query selection. Include terminal classification accuracy for decided models and report abstention separately, no scoring hidden labels for abstained worlds.

## Failure controls, defined before scoring
1. **Late-switch, pool-indistinguishable controls:** eight cases (one per source predicate), where a hypothetical rule change only begins at length >=14. H0 and H1 are identical on all training and query-pool words; a strategy must ABSTAIN 8/8. This represents a mathematically nonidentifiable change given pool length <=10, not evidence of adaptability.
2. **Misspecified-class controls:** eight cases (one per source predicate), candidate H0 base vs H1 base flipped by trigger `aaaaa` at length >=6, but *true* oracle flips on unseen trigger `bbbbb` at length >=6. Query-first-disagreement from candidate pair leads to a binary answer consistent with exactly one incorrect model (typically H0), so the selector may **falsely accept**. Required detection/abstention >=6/8, measured as open-world safety gate. No candidate-class extension is allowed after observing results.

## Prespecified gates
- H6a (mechanics): active correct identification >=0.95 across 80 worlds AND absolute correct-identification gain >=0.40 compared with one-query uniform-pool random baseline.
- H6b (indistinguishability): abstain 8/8 late-switch control worlds (no unsupported semantic conclusion).
- H6c (open-world safety): abstain on at least 6/8 misspecified-class controls; **false acceptance is failure even if heldout accuracy is high**.
- **Overall H6 GO requires all H6a/H6b/H6c.** Record failure cases and strongest random-disagreement control, including if it ties active on H6a.

## Budgets and limitations
Each arm uses one oracle label per world. 80×3=240 labels for in-class arms; eight late-switch and eight misspecified controls, one label each (active only): **256 query-oracle labels total**. The 63 training labels per world are synthetic known observations; 256 terminal labels per in-class world are for evaluation only (20,480 total) and not part of 256 active oracle calls. Candidate-compute is NOT matched (active and random-disagreement inspect many model predictions, uniform random does not). No generalization from a hand-paired class family to self-authored new primitives, no use of paid or external evaluator, and no independent evaluator acceptance. The algorithm can never infer a future rule that is identical across all queried points, and a single binary disagreement label cannot detect a third unlisted model because it must match one candidate's Boolean prediction.
