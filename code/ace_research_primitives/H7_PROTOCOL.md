## Research question
Can a bounded R1 mechanism construct a *new residual finite-memory readout* from counterexamples to an incumbent model, rather than choose a fixed researcher-enumerated list of H6 triggers? The model class (contiguous substring detection and XOR residual) **is researcher-authored**. This tests construction of new instances/transition memory only, **not invention of an unrestricted computational class**. S2 owns arithmetic AST search; R7 owns broader active acquisition/calibration.

## Bank, phase separation and budgets
- Binary alphabet a/b; the **base predictor is supplied to every method as privileged background knowledge**. Four base functions: equal_counts, a_mod3, contains_ab, dyck (from H6). The base is correct on all initial words of length 0..5 (63 labels), but the mechanism may differ on longer words.
- **64 in-class tasks:** cartesian product of those four bases × all 16 length-four binary substrings, in lexicographic order. Truth = base(word) XOR [len(word)>=6 and pattern occurs in word]. The 16 target literal values are kept **entirely out of the learner**. Their values are not passed into proposal construction or scoring policy.
- Each task index i: query pool all binary words of lengths 6..10 in length-lex order; choose **128 unique training-query words** using `random.Random(20261106+30000+i).sample(pool,128)`, then **128 unique validation-query words** using a separate `random.Random(20261106+40000+i)` sampling from pool minus the query words. No adaptive oracle query selection in H7. Do not train/retrain on validation. Holdout: 256 unique words sampled by `random.Random(20261106+50000+i)` from lengths 11..13, independent of training and validation. Distinct lengths ensure no overlap. No target-aware filtering; failures due to uninformative samples remain failures.
- Oracle budget per main task: 128 query labels +128 validation labels =256. Initial 63 labels, 256 terminal holdout labels used only for evaluation. Across 64 in-class worlds: 16,384 query/validation labels +16,384 holdout, plus 4,032 base initial labels.
- Train label `residual = oracle(word) XOR base(word)`. Collect contiguous substrings of lengths **2,3,4,5** appearing in **residual-positive training words**, without prelisting candidate values. At most 100 unique candidates (alphabet and max n bound) and 30,000 string operations/task; overflow fails closed. A candidate readout is [len(word)>=6 and substring in word]; filter candidates to **zero training residual errors** and >=2 training residual positives. For model acceptance require **zero validation residual errors** and >=2 validation residual positives. If none, abstain (predict base as a conservative fallback but do not count it as a newly accepted primitive). Tie: prefer shortest substring then lexicographic. Fully lock candidate after validation, never consult holdout for selection.
- Strong controls: (a) always base; (b) fixed H6 five length-five trigger readouts, train-only select the candidate with fewest train errors, with validation-only acceptance under the same zero-error/support conditions; (c) a hindsight oracle selecting the highest **holdout** accuracy among base and all five fixed triggers, used exclusively as an optimistic ceiling comparator, not for any live decision; (d) residual word memorizer on train queries (unseen full-string inputs predict base). All arms see identical query/validation observations. Code compute is **not matched**, label count is matched.
- Report per-task candidate name and origin examples, number of candidates evaluated, query and validation errors, holdout correct/256, confidence/abstention, and first failed heldout word. Note oracle knowledge of base is unrealistically privileged.

## Negative controls (8 distinct tasks; not part of main 64)
Four **late drift** controls: same base names, truth = base XOR [len>=14 and contains 'abba']; all training/validation words <=10. System must abstain on novelty (no positive residual). Evaluate on 256 unique words lengths 14..17 seeded `20261106+70000+j` solely for illustrating false generalization; no holdout input influences training or selection.
Four **out-of-class residual** controls: same base names, truth = base XOR [len>=6 and number_of_a(word) is even]. Query/validation words generated with the same recipe at indices 64+j; holdout independent using same length-11..13 recipe. A substring candidate cannot generally model a global parity predicate; require abstention when no exact candidate. Keep actual false acceptances (if any).

## Predefined falsifiable gates
H7a passes **only** if all three:
1. >=56/64 main tasks accept a newly data-constructed substring feature;
2. mean holdout accuracy of the **constructed-or-base fallback** across all 64 tasks >=0.95;
3. average constructed-or-base holdout advantage over **per-task hindsight-best** of [base+5 fixed H6 triggers] >=+0.10 absolute.
H7b passes if >=7/8 negative controls **abstain from newly constructed features**. Count acceptance on late drift or out-of-class task as a safety failure regardless of holdout accuracy.
**Overall H7 GO only if both H7a and H7b pass.** One fixed-query bank and seeds. No post-score changes to gates; exploratory fixes/variants must be disclosed separately.
