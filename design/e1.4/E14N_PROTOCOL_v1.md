# E1.4n — pre-score conditional representation expansion protocol

**Parent** [E1.4m result](https://github.com/dianzherdiana25-hash/ACE/commit/5d96b4188fb63fdc719b6e87d86be7cb8665ece5) · [Issue #7](https://github.com/dianzherdiana25-hash/ACE/issues/7).

- Use 56 fresh public input blocks and 72 worlds, with prior raw fingerprints excluded. Per family, test eight natural length-five or length-six targets, eight matched in-model controls, nine repairable targets split evenly across lengths seven, eight, and nine, three ambiguous targets, four no-trigger targets, and four length-ten outside targets. The matched worlds reuse raw demos, observations and probes from eight repair blocks, with targets from the live old classes and the same initial blank labels. Keep all worlds.
- Start with 32 demos. A common scripted order reveals up to four oracle-labeled observations to all methods. The repair bank gives one positive observation that eliminates the old classes, then an exact-length positive and shorter negative foils when these are new event strings. This deliberately provides evidence that can identify the expanded model. The ambiguous bank ends after one positive with more than one live expansion. No-trigger worlds receive only a negative observation. In the outside bank, every length-nine subwindow of the length-ten positive has already been seen negative, so neither original nor expanded classes can fit. Natural demos and probes are drawn before sampling their target. All eight held-out probes have 14 events and are never sent to the worker. In stress cases four positives have different contexts and four negatives contain proper subwords.
- Every method fits original exact contiguous-word classes five and six. When both classes become empty and a positive observation exists, compare holding predictions, exhaustive fixed length seven, exhaustive lengths seven through nine, and directed expansion. Directed expansion uses the first positive observation as an anchor. For each allowed length, it proposes only event words in that observation that reproduce its complete label, then checks all observations in the same order as enumeration. The anchor is checked first for every method. The bounded DSL adds lengths seven through nine to the existing exact-word grammar. No executable code is accepted as a candidate. If the initial classes remain live, the system makes no proposal. If no compatible candidate remains, it abstains.
- Cap expansion at 30,000 candidates per method per step, with the complete three-length enumeration inside the cap for both families. Record candidate fits, short-circuit label comparisons, separate anchor-window checks and measured CPU time. Full enumeration and directed search must produce identical exact candidate sets. The baseline intentionally enumerates and serves as a completeness and cost reference. The worker gets only the family and currently visible labeled observations. Predict selectively only when the nonempty candidate set agrees on the entire held-out output. Record coverage, errors, and false positives rather than crediting abstentions as correct predictions.
- **Repair GO** requires at least 8/9 repairable worlds per family with all eight held-out outputs correctly covered by directed expansion, a strict improvement over fixed length seven in each family, no more than 5% as many candidate fits as exhaustive lengths seven through nine on repairable worlds, identical survivor sets to full enumeration at every stage, no expansion attempts on natural, matched or no-trigger worlds, and no accepted predictions after the final outside observation. Otherwise report HOLD. **Rare HOLD** and **NATURAL_HOLD** remain separate. This experiment estimates conditional repair under supplied evidence. It does not re-estimate autonomous counterexample acquisition.
- Freeze bank, code and thresholds before scoring. Bind the upstream manifests, use native sandbox and typed messages, checkpoint every world, and run bounded score, fresh replay and independent oracle audit. Preserve all results, including ambiguity, failures, and unsupported targets.
