# E1.4m — pre-score active counterexample protocol

**Parent** [E1.4l result](https://github.com/dianzherdiana25-hash/ACE/commit/2338bed3b01cdcb8bb0296ed4133a784ea8065f2) · [Issue #6](https://github.com/dianzherdiana25-hash/ACE/issues/6).

- Use 56 new public input blocks and 72 worlds, excluding previous raw fingerprints. For each family, six natural worlds at each length five and six provide 24 natural controls in total. Separately, each family has eight reachable and eight rare seven-event targets. Construct three independent nine-event source traces per engineered block. Reveal their six-event windows and additional decoy five- and six-event demos, with 32 demos total. Sample the reachable target from a seven-event window of the sources. Sample the rare target with both six-event subwindows absent from the demos. Source traces and target are not supplied to the worker. The reachable distribution is deliberately aligned with the announced negative-window search grammar. It is a capability diagnostic.
- For each reachable block, add a matched in-model target from the live five- or six-event class. It shares the same demos, probes, seed and initial blank labels as the out-of-model world. Four probes per engineered block contain its seven-event target, four exclude it, and all probes contain 14 events. Natural raw inputs precede target sampling. Retain all worlds.
- All arms use nine-event queries, at most eight scored candidates per round and at most four purchased labels. No repeat of a labeled event string. **Adjudication** and **falsification** use the same pool at matched state and seed, up to four padded live-motif offers plus up to four paths of overlapping observed blank six-event windows. Paths rank by the number of distinct seven-event windows not covered by a prior blank answer. Adjudication chooses the E1.4l minimax criterion, or the largest label-bucket fraction when only one class remains. It purchases only when the criterion is below one. Falsification chooses only unanimous blank queries and maximizes their untested seven-event windows. **Random** samples uniform nine-event traces without replacement among retained proposals and buys the first available one. Count scored offers, generated attempts, fit comparisons, labels and purchased events separately. Stop an arm when the version space empties, no qualifying query remains, or the cap is reached.
- Declare a contradiction only after an observed label eliminates every exact five- and six-event candidate. A remaining version space means that no contradiction was observed. Report selective predictions from unanimous nonempty candidates, including coverage and accepted errors. Rejection suppresses predictions, so reductions in errors must be read with coverage. A model rejection does not propose a replacement representation. Testing only seven-event alternatives in the proposal mechanism bounds the claim.
- **Reachable GO** if falsification detects at least 5/8 reachable worlds in each family at cap four, beats both comparison arms in each family, and no arm rejects any in-model world. **Rare GO** separately requires at least 4/8 in each family, superiority over both controls and zero false rejections. Otherwise mark the corresponding gate HOLD. Rare targets are outside the initial overlap proposal support by construction. **NATURAL_HOLD** for transfer remains separate.
- Freeze the bank, code and thresholds before scoring. Use the native isolated worker with no evaluator, condition, or target access, transactional checkpoints, bounded score and fresh replay, and independent arithmetic audit of live hypotheses, selective risk, query decisions and purchased labels.
