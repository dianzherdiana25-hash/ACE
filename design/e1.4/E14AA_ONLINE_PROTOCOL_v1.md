# E1.4aa prospective public development protocol v1

Base: `988b077dc2ff12d01d1f93fd6b1dca94036cc579`, PRs #18–#22.
No frozen bank, threshold or score is rewritten. This is a new same-project
development experiment, not independent scientific confirmation. No sealed E1.3
data, paid service, main/Tod change or merge is authorized here.

Before scoring, commit this protocol, bank, executable learner/monitor/study and
independent arithmetic oracle, then record their SHA256 lock. Do not change them
after observing results; corrections require a new version with old negatives kept.

Six source lineages are generated with fixed seed 202611051101. Three have one
periodic residual and three sum a periodic residual and a threshold residual.
They exercise synthesis beyond the previous single-predicate 175-signature family.
Supplied integer arithmetic and predicates remain researcher-authored primitives.
No unconstrained operator invention or OAIE claim follows.

Each lineage gets three distinct motif source tasks, four purchased labels each
(maximum 12 per lineage). Search fits at most two weighted predicates, with
explicit AST/candidate/evaluation/CPU limits and complete-search requirement for
conditional unique acceptance. All source journals are retained as original SQLite
files and snapshots, including pending purchases on failure. Oracle labels never
enter query selection except as purchased observations.

Each lineage has two target motif pairs and four regimes: stable; one legal
query-point needle perturbation; broad `2*(lo % 2)` perturbation; and that same
broad perturbation starting at target turn three. The target query domain is
`(lo+hi)%3 != 0`, held-out domain is its complement, within `4<=lo<=hi<=18`.
The bank and split are public synthetic development; needles are chosen before
scoring, not selected from subsequent misses. Target truth is stable within each
turn. Delayed drift occurs before the third purchased observation and prediction.
Source tasks may purchase coordinates in the target-heldout subset because they
share a transferable source operator. Thus heldout means absent from target-stage
queries, not globally unseen cost coordinates or independent source information.

Four controls per target: frozen two-check inherited use, four-check online random
monitor, four-check online disagreement monitor, and sham online inheritance.
All arms purchase exactly four target labels, including research follow-up after
quarantine, so total target purchases are matched. Frozen2 uses only the first two
labels for its decision; its latter two labels are deliberately ignored to isolate
the value of processing evidence during execution. It is an observation-use
ablation, not a claim that an efficient two-query policy consumes four labels.
Random and frozen2 share the same fixed label-blind permutation. Active checks
use disagreement against the old supplied single-predicate grammar; they do not
see target truth or held-out outcomes. Sham artifact uses base `lo+hi`.

After every purchase, reconstruct monitor state from durable receipts *before*
scoring any next prediction. Any contradicting label permanently quarantines the
inherited artifact for that four-label epoch. Pending purchases block use and
must not be automatically retried. New epochs require explicit evaluator-owned
arm identities; this experiment never resets a spent arm to gain labels.
Conditional inherited predictions require two distinct agreements. Open-world
scope always abstains; finite agreements never certify absence of drift.

Primary development contrast: post-observation erroneous inherited uses of
online-random versus frozen2 across four turns and all 120 finite cost points.
Report detection receipt/turn, current semantic exactness, held-out prediction
errors and coverage, false alarms in stable arms, and undetected needles. Report
source learning exactness on all 120 points separately. Abstention is not success.
Record all labels, source costs amortized and unamortized, graph costs, candidate
fits/evaluations, CPU, wall time, peak RSS, failures and original journals.
Maximum target purchases: 192*4=768; maximum distinct source purchases: 6*12=72.
Source acquisitions are shared across controls and target regimes; this does not
establish equal total information to an unrelated cold baseline.

Independent arithmetic checker must not import the learner's AST evaluator;
independent DFS traversal must recheck each paid graph receipt and all reported
finite-domain metrics. That is separate implementation review within this agent
team, not independent institutional custody or external scientific sign-off.
Replay uses fresh journals and checks deterministic decisions and receipts;
CPU/wall/RSS measurements are excluded from deterministic comparisons.

Expected negative limits: sparse/needle drift can be missed, no finite query policy
identifies unrestricted functions, active challengers can all be wrong, and fitting
the new bounded family may exhaust resources or remain ambiguous. Preserve all
such results and retain scientific NOT_ASSESSED / HOLD regardless of test counts.
Trusted in-process DSL evaluation is permitted for public development. Native
sandbox security is a separate gate, blocked here if UID namespaces cannot start.
