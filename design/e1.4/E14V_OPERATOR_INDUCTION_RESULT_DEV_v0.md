## Implemented

- Author-specified two-route program \`a * min(c1,c2) + b * max(c1,c2)\` with bounded integer parameter inference, rather than only a human-enumerated choice among MAX/MIN/SUM. Model family remains fixed, no new semantic operator form is generated by the model.
- Exact version-space filtering over **476** candidate models (56 single-path, 420 affine pair programs); stronger historical finite control with 140 candidates.
- Full-rank positive-evidence coefficient solver; conservative gate abstains without algebraic identifiability, even when version space has one survivor.
- Active, oracle-blind source acquisition: **269 purchased labels across 88 worlds**, at most four per world, separately audited and reused across four strategy arms. The target stage purchases **168 additional labels across 352 arms**, cap four each, all replayed. \`None\` is charged; topology resources are journaled.
- The challenge arm purchases a distinct extra graph response before acceptance; on this specific bank it provides **no acceptance improvement** beyond rank certification despite 72 extra target labels (110 versus 38). This is a justified reason not to promote it as the default.
- Fixed-seed disjoint-branch development probes and a **separate postscore shared-prefix DAG topology audit** with a different DFS implementation. The latter performs 528 distinct graph/oracle comparisons across 88 worlds, and 352 arm outcome comparisons.

## Failures and corrections found during this sprint

1. Initial metric counted unaccepted version-space consensus as prediction coverage. Fixed: abstained arms now count **zero** accepted predictions.
2. A branch prematurely broke the target loop when exactly one candidate remained even though its numeric parameters lacked a rank certificate. Fixed: the verified policy may purchase a separating equation from the remaining target budget. Added a targeted recovery test.
3. Early uncorrected snapshot had 52 accepted-correct / zero wrong for verified guard; corrected snapshot has **72 accepted-correct / zero wrong**. Preserve the audit trail; neither is independent science.
4. A monolithic partial-workspace test command timed out. Six bounded test groups separately reported **59+36+50+5+8+11 = 169/169 PASS**. The full ACE historical 114+ checkout regression and native worker isolation have **not** been run from this branch.
