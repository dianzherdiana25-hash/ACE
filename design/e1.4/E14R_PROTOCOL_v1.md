# E1.4r — pre-score diagnostic receipts for inherited representations

E1.4p produced 12 learned source artifacts and showed a failure when one neutral calibration label did not contradict an inherited artifact. E1.4q showed that several exact routes with different tolls can increase the information in one cost label. Reuse the audited E1.4p artifacts without any new source observations. This study tests whether a successor can qualify or reject a stored artifact before use.

Freeze a fresh public target block per lineage, with the same ten held-out graphs across five paired worlds. Three worlds follow one of three declared interpretations of each artifact: identity, a flip of the final event, and a flip of the penultimate event. A fourth world follows the same-length complement, which is outside the declared interpretations. A fifth uses the first n−1 events of the original word. This shorter word can match a route and return the same cost as a longer interpretation. Keep the two out-of-menu strata separate. No target label or probe is available to the artifact source or query generator.

Compare passive inheritance after one shared neutral graph, a chain targeted at the original motif with a positive receipt, and a packed graph covering all three declared interpretations with the same positive receipt rule. The passive arm inherits the original artifact after a null response. The two diagnostic arms release a motif only if a non-null response identifies exactly one of the declared interpretations. Otherwise they abstain. The packed graph shares the first n−3 events and gives each remaining path a distinct toll. Each arm gets one evaluator label and at most 16 nodes and 16 edges. Record measured structure and performance costs. The primary comparison treats each lineage as one independent block and treats the five worlds as paired counterfactuals.

**Mapped GO** requires at least 10/12 complete correct cases in each mapped stratum, at least six more complete correct mapped worlds than either control, and no accepted predictions in the 12 same-length complement worlds. **Robust GO** additionally requires zero incorrect accepted probes across all shorter-word stress worlds. Report both gates regardless of their outcome. A pass supports conditional reuse and selection among supplied interpretations. Retain NATURAL_HOLD and the original E1.4o graph-chain HOLD.

Freeze source, bank and protocol before scoring. Run score, separate replay and independent oracle audit using the verified worker boundary. The worker sees only the typed artifact, strategy, and one acquired label per world. Audit persisted lineage against E1.4p, disjoint probe fingerprints, chosen graphs, permitted resources and paired probe predictions.
